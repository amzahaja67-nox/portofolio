# Hamzah Portfolio — HTML statis

Buka `index.html` langsung di browser, atau buka folder ini di VS Code lalu gunakan ekstensi Live Server.

Tidak membutuhkan Node.js, npm, atau instalasi package. Struktur file dipisahkan menjadi:

- `index.html` untuk struktur halaman
- `styles.css` untuk tampilan
- `script.js` untuk interaksi
